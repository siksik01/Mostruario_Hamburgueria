# Burger Branding Showcase

Crie um site completo, profissional, visualmente marcante e extremamente bem acabado para uma hamburgueria fictícia chamada:

SUA HAMBURGUERIA

IMPORTANTE:
Este projeto será utilizado como DEMONSTRAÇÃO / MOSTRUÁRIO comercial para apresentar meu trabalho a possíveis clientes.

O site deve parecer um site real de uma hamburgueria profissional, desenvolvido por uma agência de design e desenvolvimento especializada em restaurantes.

TODAS as informações da empresa devem ser fictícias.

Use como principal referência visual a imagem anexada neste prompt. A imagem deve servir como referência de direção de arte, composição, hierarquia, proporções, tratamento das imagens, tipografia, contraste, ritmo visual e estrutura geral.

NÃO copie literalmente a marca, logo, textos, identidade visual, produtos ou elementos proprietários da referência.

Crie uma identidade visual ORIGINAL para "SUA HAMBURGUERIA", porém mantendo o mesmo nível de qualidade visual e profissionalismo da referência.

==================================================
1. OBJETIVO
==================================================

O objetivo é criar um site que uma hamburgueria real poderia utilizar comercialmente.

O site deve transmitir:

- qualidade
- desejo
- sabor
- confiança
- personalidade
- profissionalismo
- rapidez
- experiência gastronômica

O primeiro impacto precisa ser muito forte.

O site deve vender a sensação do produto visualmente antes mesmo do usuário ler os textos.

A fotografia dos hambúrgueres deve ter papel fundamental no design.

NÃO criar apenas uma landing page genérica.

Criar uma experiência completa de site de restaurante.

==================================================
2. DIREÇÃO DE ARTE
==================================================

A referência anexada deve ser analisada principalmente pela sua COMPOSIÇÃO.

A estética desejada é:

- editorial
- publicitária
- gastronômica
- urbana
- moderna
- forte
- premium
- energética

A página deve ter ritmo visual.

Não criar todas as seções seguindo exatamente a mesma estrutura.

Cada seção deve possuir uma composição diferente, mantendo a mesma identidade visual.

Exemplos de composição:

- hero com texto à esquerda e fotografia grande à direita
- faixa horizontal de diferenciais
- cardápio em grade
- seção promocional dividida em blocos
- seção institucional com outra composição
- localização em duas colunas
- CTA final forte

O site deve parecer uma campanha de branding completa, e não uma sequência de componentes pré-fabricados.

==================================================
3. EVITAR APARÊNCIA DE SITE GERADO POR IA
==================================================

ESTA PARTE É MUITO IMPORTANTE.

NÃO criar um site com os padrões visuais comuns de páginas geradas automaticamente por IA.

EVITAR ABSOLUTAMENTE:

- glassmorphism
- cards de vidro
- gradientes roxo/azul
- gradientes aleatórios
- fundos com blobs
- formas abstratas 3D
- excesso de elementos flutuantes
- excesso de border-radius
- cards excessivamente arredondados
- sombras exageradas
- excesso de ícones
- layout excessivamente centralizado
- seções todas iguais
- grandes espaços vazios sem propósito
- visual de startup
- visual de SaaS
- visual futurista
- estética de dashboard
- botões gigantes em formato de pílula
- excesso de animações
- textos genéricos de marketing
- títulos genéricos de IA
- visual excessivamente minimalista e vazio

NÃO tentar fazer o site parecer "tecnológico".

O foco é RESTAURANTE / GASTRONOMIA / BRANDING.

O resultado precisa parecer feito por um designer profissional.

Antes de finalizar qualquer seção, verificar visualmente:

"Isso parece um site real de uma hamburgueria profissional ou parece um template de IA?"

Caso pareça um template de IA, refazer a composição.
